Servicios de almacenamiento en AWS

¿Cómo funciona Amazon S3?

Amazon Simple Storage Service (Amazon S3) es un servicio de almacenamiento de objetos. Permite guardar y recuperar archivos desde internet con escalabilidad, controles de acceso y distintas opciones de almacenamiento.

Explorar los conceptos

Las piezas principales

S3 organiza los datos en contenedores y objetos. Cada objeto incluye los datos del archivo, metadatos y una clave que lo identifica dentro de su bucket.

Bucket

Es el contenedor donde se almacenan los objetos. Se crea en una región de AWS y su nombre debe ser único dentro de la partición de AWS.

Objeto

Es el archivo almacenado junto con sus metadatos. Por ejemplo, una imagen, un documento o un archivo de respaldo.

Clave (key)

Es el identificador del objeto dentro del bucket, como imagenes/logo.png. Las carpetas que parecen existir en S3 suelen ser parte de esa clave.

Objeto almacenado o recuperado

Una aplicación puede cargar, consultar o eliminar objetos mediante la consola de AWS, la API, herramientas como AWS CLI o un SDK. AWS verifica los permisos antes de permitir la operación.

Almacenamiento según el uso

Las clases de almacenamiento permiten elegir opciones adecuadas para la frecuencia de acceso y el tiempo de conservación. Algunas clases están diseñadas para acceso frecuente; otras, para archivo de largo plazo.

Acceso frecuente

Útil para contenido que se consulta regularmente, como recursos de una aplicación.

Acceso poco frecuente

Puede ser apropiado para datos que se conservan, pero se consultan ocasionalmente.

Archivo

Orientado a datos de larga conservación que pueden tolerar tiempos de recuperación mayores.

Los precios y condiciones dependen de la clase, la región, las solicitudes y la transferencia de datos. Consulta la documentación y la calculadora de precios de AWS antes de elegir.

Seguridad y administración

Permisos

AWS Identity and Access Management (IAM) y las políticas de bucket ayudan a definir quién puede acceder y qué acciones puede realizar.

Cifrado

S3 ofrece opciones para cifrar los datos. Configura el cifrado y la gestión de claves según los requisitos de tu organización.

Versionado y ciclo de vida

El versionado puede conservar distintas versiones de un objeto. Las reglas de ciclo de vida permiten administrar o mover objetos con el tiempo.

Buena práctica: mantén el acceso público bloqueado salvo que tengas un motivo claro para habilitarlo. Concede solo los permisos necesarios y evita guardar credenciales de AWS en el código fuente.

Ejemplo práctico

Para publicar imágenes de una aplicación, puedes crear un bucket en la región adecuada, configurar permisos seguros y cargar cada imagen con una clave como productos/camiseta-01.jpg. La aplicación podrá acceder a ella usando el método de autorización que hayas configurado.

Material introductorio. Revisa la documentación oficial de AWS para conocer las opciones y límites vigentes de Amazon S3.
